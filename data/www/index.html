You are given a list of binary numbers (each of the same length). Determine two rates:

  • Gamma rate - the number formed by taking the most common bit in each column.
  • Epsilon rate - the number formed by taking the least common bit in each column.

Compute the decimal value of gamma and epsilon, then return the product: power = gamma * epsilon.

Example input:

00100
11110
10110
10111
10101
01111
00111
11100
10000
11001
00010
01010

Example output for the input above:

Power consumption: 198
(Gamma=22, Epsilon=9)

Notes:

  • Input lines are treated as binary strings.
  • When counting bits per column, ties will not occur in this example.
